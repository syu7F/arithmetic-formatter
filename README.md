# Arithmetic Formatter

A Python project that formats multiple arithmetic problems side-by-side, part of the freeCodeCamp Scientific Computing with Python certification.

## Features
- Arranges addition and subtraction problems vertically and side-by-side.
- Automatically validates input data for common errors:
  - Maximum of 5 problems at a time.
  - Only allows `+` and `-` operators.
  - Numbers must only contain digits and be a maximum of 4 digits long.
- Optional parameter to display the correct answers.
